# 浙大校园网助手

浙大校园网助手是用 Rust 编写的 Windows 10/11 x64 托盘程序。它通过深澜 Srun 门户检查和恢复校园网认证，并显示使用的物理网卡、本机 IP、认证入口和最近检查时间。

## 安装和使用

1. 从 GitHub Releases 下载 Windows x64 便携包，解压到固定目录，运行 `ZjuNetAssistant.exe`。
2. 填写校园网账号和网络密码，按需勾选「保存账户密码」「自动认证」和「登录系统后启动」，然后点击「保存设置」。密码留空会沿用同一账号的当前密码。更换账号时请重新输入密码。
3. 网卡和入口可保持自动选择。点击「手动认证」立即尝试登录，或点击「立即检查」查看状态。手动检查只查询状态。
4. 关闭窗口后，程序继续在托盘运行。右键托盘图标可暂停自动认证、立即检查或退出。鼠标悬停可查看详细状态。

| 托盘颜色 | 认证状态 |
| --- | --- |
| 绿色 | 已认证 |
| 蓝色 | 等待首次检查或正在认证 |
| 橙色 | 未认证或状态未知 |
| 灰色 | 网卡未连接 |
| 红色 | 门户异常或认证失败 |

例行检查沿用上次的托盘颜色。状态栏中的「互联网」独立显示外网探测结果。

## 升级、移动和卸载

- **原地升级**：从托盘右键菜单退出程序，将新版文件覆盖到原目录，再运行新版。自启项会继续使用原路径，配置与保存的凭据可继续使用。
- **移动到新目录**：先从托盘退出旧版，再启动新目录中的程序。如果启用了登录自启，保持该选项勾选并点击「保存设置」，让 Windows 记录新路径。程序一次只运行一个实例，旧版在托盘运行时再双击另一份 EXE，会打开已运行实例的窗口。
- **卸载**：取消勾选「登录系统后启动」和「保存账户密码」，点击「保存设置」，确认成功后从托盘退出，再删除程序目录。需要清除本地配置和日志时，删除下文列出的数据目录。

登录自启使用当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`。条目名为 `ZjuNetAssistant`，命令包含程序的完整路径和 `--background`。普通桌面会话可在应用内设置，无需管理员权限。

## 认证和网络检查

程序在物理以太网和 Wi‑Fi 上检查 `net.zju.edu.cn`、`net2.zju.edu.cn` 和 `net3.zju.edu.cn`，按网卡、网关和网段缓存可用入口。门户 DNS 和 HTTPS 连接都使用选定的物理网卡。认证请求只发往上述域名的有效 HTTPS 入口。

检查周期默认 60 秒，可设为 15～3600 秒。网卡、IP 地址或默认路由变化也会触发检查。临时失败会延长重试间隔。收到账号或密码错误时，程序会暂停自动认证。更新凭据后可手动验证。

外网检查沿 Windows 当前路由访问小米、Cloudflare 或 Google 的 HTTPS 探测点，可使用 Clash TUN 提供的路由。若 TUN 策略阻断物理网卡到门户或校园 DNS 的连接，在 VPN 客户端为这些目标配置分流。IPv6 可用于外网探测，门户认证使用 IPv4。

适用范围为上述入口的校园网网页认证。L2TP、校外 VPN 和 ZJUWLAN-Secure 的 802.1X 接入使用各自的配置方式。

## 配置、密码和日志

| 数据 | 保存位置 |
| --- | --- |
| 账号和应用设置 | `%LOCALAPPDATA%\ZjuNetAssistant\config.json` |
| 保存的密码 | Windows 凭据管理器的普通凭据 `ZjuNetAssistant/campus-network` |
| 诊断日志 | `%LOCALAPPDATA%\ZjuNetAssistant\events.log` |

点击「打开日志」可进入数据目录。界面显示最近 200 条重要事件。文件日志约每 1 MiB 轮转一次，保留 4 个历史文件。

取消「保存账户密码」并成功保存后，程序移除保存在凭据管理器中的密码，当前进程仍可使用已有密码，直到退出。分享日志或截图前，请遮盖账号、本机 IP 与其他个人信息。

## 从源码构建

准备 Rust Windows x64 工具链，在源码目录运行：

```powershell
.\build.ps1 -Test
```

生成的程序位于 `dist/ZjuNetAssistant.exe`，运行便携版无需安装 Rust。工具链选择、凭据测试和 Release 打包步骤见 [贡献与发布指南](CONTRIBUTING.md)。
